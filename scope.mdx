<Warning>
  Скилы **cdm-*** применяются только к задачам в каталоге  
  `Work Task/D00002 - Развитие HD/R03 - Модель данных KDW (CDM)/` и вложениях.
</Warning>

| Требование | Описание |
| --- | --- |
| `$TASK_DIR` | Папка задачи внутри корня R03 |
| Источники | Пути к файлам для intake/extract — внутри R03 |
| `$TARGET_DIR` (save) | Папка назначения — внутри R03 |
| Шлюз оркестратора | При пути вне R03 → `blocked`, дочерние скилы не вызываются |

При первом запуске оркестратор может создать `work_docs/config_cdm.json` с полем `scope_root` после подтверждения папки задачи.

<Tip>
  Точка входа для аналитика в R03: `README-CDM-SKILLS.md` в корне R03.  
  Канон скилов: `agent-hd/cs-skills/cs-skills-cdm/`.
</Tip>
